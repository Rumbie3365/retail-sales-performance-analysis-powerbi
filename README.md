# Retail Sales Performance Analysis Using Excel, SQL Server and Power BI

## Project Overview

This project analyses a synthetic retail sales dataset using Excel, SQL Server / T-SQL and Power BI. The purpose of the project is to evaluate sales performance, profit, customer segments, product categories, regional performance, sales channels, returns and target achievement.

The project demonstrates practical business data analysis skills outside the health sector and shows how raw sales data can be converted into useful business insights through an interactive Power BI dashboard.

## Tools Used

- Microsoft Excel
- SQL Server / T-SQL
- Power BI
- DAX
- Python
- Synthetic retail sales dataset

## Dataset

The dataset is synthetic and was generated for portfolio use. It does not contain real customers, real transactions, or private company data.

The dataset includes:

- Sales transactions
- Product dimension
- Customer dimension
- Date dimension
- Sales targets
- Returns data

The synthetic data was generated using the Python script included in the `scripts/` folder.

## Business Questions

1. What are the total sales, profit, profit margin, orders, average order value and return rate?
2. How do sales and profit trend over time?
3. Which product categories and products generate the most sales?
4. Which categories have the strongest profit margins?
5. Which customer segments and provinces generate the most sales?
6. Which sales channels perform best across customer segments?
7. What business recommendations can be made from the analysis?

## Key Metrics

- Net Sales: approximately $185.3K
- Total Profit: approximately $54.5K
- Profit Margin: approximately 29.40%
- Orders: 1,000
- Average Order Value: approximately $185.31
- Return Rate: approximately 7.30%

## Key Findings

- Technology generated the strongest sales and profit performance.
- Consumer customers contributed the highest sales compared with Corporate and Small Business segments.
- Gauteng and Western Cape were the strongest-performing provinces by net sales.
- Online and retail store channels were important contributors to overall sales performance.
- Return rate was approximately 7.30%, which should be monitored as part of customer satisfaction and product quality analysis.

## Business Meaning

Strong product and regional performance can support better stock planning, sales campaigns and channel strategy. The dashboard helps decision-makers quickly understand which categories, customer segments, provinces and sales channels are driving performance.

## Data Limitations

- The dataset is synthetic and was created for portfolio practice.
- Sales values represent realistic retail patterns but are not real company financial records.
- Customer names and transactions are fictional.
- The analysis is descriptive and does not include forecasting or advanced statistical modelling.

## Recommendations

- Prioritise high-performing categories such as Technology while monitoring profit margins.
- Use province-level results to guide stock planning and regional sales campaigns.
- Monitor return patterns to identify possible product, delivery or customer experience issues.
- Strengthen online and retail store channels because they contribute strongly to sales.
- Extend the project later with forecasting, customer retention and marketing analysis.
